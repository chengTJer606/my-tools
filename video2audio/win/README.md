# 视频转音频工具

一个便携、可视化的视频音频提取工具。基于 Python + ffmpeg，无需安装，整个文件夹拷到哪里就能在哪里运行。

## 文件组成

| 文件 | 说明 |
| --- | --- |
| `video2audio.pyw` | 主程序（Python 图形界面），`.pyw` 双击无控制台窗口 |
| `启动.bat` | 启动器，双击即调用本机 Python 启动 GUI |
| `ffmpeg.exe` | 音频编解码引擎（约 62 MB，便携内置） |
| `README.md` | 本说明文件 |

## 使用方法

### 方式一：双击启动

1. 双击文件夹中的 **`启动.bat`**。
2. 弹出 GUI 窗口后即可操作。

### 方式二：直接双击脚本

如果系统已将 `.pyw` 关联到 Python（安装时勾选过 "Associate"），直接双击 `video2audio.pyw` 也能启动。

## 操作流程

1. **选择视频**：界面顶部三个按钮任选其一：
   - `选择视频文件…`：弹窗中可单选或多选（按住 `Ctrl` 或 `Shift`）。
   - `选择文件夹（批量）…`：递归读取该文件夹及所有子文件夹中的视频。
   - `移除选中` / `清空列表`：编辑任务列表。
2. **设置参数**：
   - **音频格式**：默认 `MP3 (192kbps)`，可选 128/192/320 kbps MP3、M4A/AAC、WAV 无损、原流复制（速度最快）。
   - **文件名后缀**：默认 `_audio`，生成文件形如 `视频_audio.mp3`。
   - **转换成功后删除原视频**：勾选后，每个视频转出音频成功即立即删除原视频（永久删除，不可恢复）。点击「开始转换」时会弹二次确认对话框。
3. **开始转换**：点击右下角 `▶ 开始转换`，任务列表实时显示每个视频的状态（等待 / 转换中 / 完成 / 失败），并实时记录：
   - **原视频大小**：加入列表时即读取
   - **输出音频大小**：转换完成后显示
   - **处理耗时**：从该视频开始转换计时，到转换结束（含失败时的耗时）
4. **结果位置**：所有输出文件都生成在 **对应输入文件的同一目录** 下。
5. **总用时**：界面最下方状态栏末尾实时显示自开始转换起的累计总用时，全部完成后停止。

## 支持的视频格式

`.mp4 .mkv .avi .mov .flv .wmv .webm .ts .m4v .mpg .mpeg .3gp .rmvb .rm .vob .ogv .mts .m2ts .f4v`

## 输出格式说明

| 格式 | 扩展名 | 特点 |
| --- | --- | --- |
| MP3 (192kbps) | `.mp3` | 默认选项，体积小、兼容性最好 |
| MP3 (320 / 128 kbps) | `.mp3` | 高质量 / 更小体积 |
| M4A / AAC | `.m4a` | 同等音质下比 MP3 略小 |
| WAV (无损 PCM) | `.wav` | 无损，体积较大，适合后期剪辑 |
| 原流复制(最快) | 视源而定 | 不重新编码，直接抽取视频中的音频流，秒级完成 |

> **原流复制** 会自动探测源音频编码，按需输出 `.mp3` / `.m4a` / `.aac` / `.ac3` / `.ogg` / `.flac` / `.wav` 等。
> 如果源视频本身没有音频流（纯无声视频），该选项会失败，请改用其他编码格式。

## 输入 / 输出示例

假设输入 `D:\录屏\meeting.mp4`，后缀 `_audio`：

- 输出：`D:\录屏\meeting_audio.mp3`（同目录、原名 + 后缀）

假设批量处理 `D:\录屏\` 下三个文件，输出同样落在该目录：

```
D:\录屏\
  ├─ a.mp4            （输入）
  ├─ a_audio.mp3      （输出）
  ├─ b.mkv            （输入）
  ├─ b_audio.mp3      （输出）
  ├─ sub\
  │   ├─ c.mov        （输入）
  │   └─ c_audio.mp3  （输出）
```

## 依赖

- **Python 3.7+**：仅用了标准库（tkinter、subprocess、threading、queue），无需额外安装。
- **ffmpeg.exe**：已内置在文件夹中。若误删，可从 <https://www.gyan.dev/ffmpeg/builds/> 下载 `ffmpeg-essential` 解压版，将 `bin\ffmpeg.exe` 放回本文件夹即可。

## 常见问题

### 双击 `启动.bat` 弹出 "Python was not found"

本机尚未安装 Python，或未加入 PATH。请从 <https://www.python.org/> 下载安装，安装时勾选 **Add Python to PATH**。

### 转换失败 "未检测到音频流"

源视频本身就是无声的，无法提取音频。

### 想要更高的音质

选择 `MP3 (320kbps)` 或 `WAV (无损 PCM)`。

### 想把整个工具移到别的电脑

直接把整个 `视频转音频工具` 文件夹拷贝过去即可。只要目标机器装有 Python，双击 `启动.bat` 就能用。

### 勾选了「删除原视频」反悔了

只要还没点「开始转换」，取消勾选即可。已开始转换的话，对后续未处理的视频可先点「移除选中」从列表里去掉，或在弹出的确认对话框里点「否」。已经删除的原视频不可恢复。

### 失败的视频会怎样

转换失败的视频会在状态列显示「失败」，状态栏汇总「成功 N，失败 M」，并自动弹窗列出每个失败文件的具体原因。原视频不会被删除（即使勾选了删除）。

## 工作原理

GUI 主线程仅负责交互；点击 "开始转换" 后会启动一个后台线程，依次对每个视频调用同目录的 `ffmpeg.exe` 完成实际编解码。任务状态通过线程安全的队列回传给主线程刷新界面，所以界面在转换过程中不会卡死。
